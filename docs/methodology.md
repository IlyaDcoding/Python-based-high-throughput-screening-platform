# Методика расчёта и защита проекта

## Задача и границы эксперимента

Проект использует критерии Topic 7 из Project plan.docx. Для первого запуска выбраны thermal barrier coatings (TBC), потому что в одной работе опубликованы сопоставимые пары thermal conductivity и thermal expansion coefficient для трёх высокоэнтропийных образцов. Другие работы расширяют базу и показывают, зачем разделять серии измерений. Использован опыт с объёмной керамикой одного семейства и протокола. [Huang et al., Coatings, 2026](https://www.mdpi.com/2079-6412/16/1/79)

1. Сначала выбираем семейство, класс, применение и один вид происхождения данных. Для каждого свойства отдельно проверяем форму образца, метод, поправки, температуру или температурный интервал, частоту, давление и дополнительные условия. В расчёте к 25 °C применяются только значения thermal conductivity, а к 1000 °C только значения thermal expansion coefficient. Каждое свойство сравнивается между образцами при одинаковых для него условиях.
2. Проверяем наличие одного сопоставимого значения и применяем включительные пороги. Из семи высокоэнтропийных фторитовых цирконатов в базе четыре относятся к другой серии и исключены по условиям. Если одновременно доступны несколько результатов для того же кандидата и критерия, нужна явная научная процедура выбора или агрегации. Программа помечает такого кандидата как исключённого.
3. Строим матрицу X размера n × m для оставшихся n образцов и m критериев с положительным весом. Минимумы и максимумы берутся по одному столбцу, уже после фильтрации. В базовом сценарии включены k ≤ 1.8 W/(m·K) и CTE ≥ 10.8 × 10⁻⁶ K⁻¹. Это учебные границы конфигурации. Стремление к большей CTE в наблюдаемом узком диапазоне иллюстрирует задачу согласования с более расширяющимся слоем. В инженерном сценарии следует задать диапазон CTE конкретной подложки и bond coat.

## Формулы

Пусть xᵢⱼ — значение j-го свойства i-го образца, Lⱼ и Uⱼ — минимум и максимум в допущенном пуле. В формулах zᵢⱼ ориентирован так, что большее число лучше.

| Операция | Формула |
| --- | --- |
| Максимизация | zᵢⱼ = (xᵢⱼ − Lⱼ) / (Uⱼ − Lⱼ) |
| Минимизация | zᵢⱼ = (Uⱼ − xᵢⱼ) / (Uⱼ − Lⱼ) |
| Нормирование весов | pⱼ = wⱼ / Σₖwₖ, где wⱼ ≥ 0 и Σₖwₖ > 0 |
| Взвешенная сумма | Sᵢ = Σⱼpⱼzᵢⱼ. Для всего пула S = Zp |

- Почти равный диапазон определяем по условию |U − L| ≤ 10⁻¹² max(|U|, |L|). В этом случае z = 0.5 у всех образцов, поэтому критерий не меняет их порядок. Это относится и к пулу из одного образца. Одинаковые для всех оценки могут сжимать разброс баллов.
- Пропуск активного свойства или свойства с порогом исключает образец с указанием причины. Реальные нули для свойств, допускающих нулевое значение, сохраняются. Измерения в разных единицах приводятся по x′ = ax + b, а ширина неопределённости по u′ = |a|u.
- Вычисления идут в float64. Перед суммированием веса делятся на наибольший вес, что уменьшает риск переполнения. При переполнении разности крайних значений min–max использует масштабированные границы. При сравнении с порогом применяется относительный допуск 10⁻¹². Баллы сохраняются с вычисленной точностью. Только ключ ранга округляется до 12 знаков после точки. Одинаковому ключу присваивается одинаковое место с пропуском следующих позиций, например 1, 1, 3.
- Для анализа чувствительности поочерёдно меняем один положительный вес wⱼ на 0.8wⱼ и 1.2wⱼ, снова нормируем веса и пересчитываем S при неизменной матрице Z. Всего получаем пять сценариев для двух критериев. Эта проверка оценивает выбор весов. Доверительные интервалы для баллов она не оценивает.

## Проверка вручную

Данные для расчёта взяты из Table 2. Для k использованы результаты при 25 °C с поправкой на пористость по Eq. (5). Для CTE взяты значения, приведённые авторами при 1000 °C. [Huang et al., Coatings, 2026](https://www.mdpi.com/2079-6412/16/1/79)

| Образец | k, W/(m·K) | CTE, 10⁻⁶ K⁻¹ | z(k) | z(CTE) | 0.65z(k) + 0.35z(CTE) |
| --- | ---: | ---: | ---: | ---: | ---: |
| SGDETZO | 1.58 | 11.39 | 1 | 1 | 1.000000 |
| GDHETZO | 1.72 | 11.30 | 0 | 0.50 / 0.59 | 0.296610 |
| GDHEYZO | 1.66 | 10.80 | 0.06 / 0.14 | 0 | 0.278571 |

Например, для GDHEYZO числитель при минимизации k равен 1.72 − 1.66 = 0.06, знаменатель равен 1.72 − 1.58 = 0.14. После умножения на 0.65 получается 0.278571. Для ручной проверки на учебных числах используйте A = (2, 8), B = (4, 10), C = (6, 12). Первый столбец минимизируется, второй максимизируется, веса 3 и 1. Нормированные строки равны (1, 0), (0.5, 0.5), (0, 1), а итоговые баллы равны 0.75, 0.50 и 0.25. Pytest проверяет оба примера.

SGDETZO находится на первом месте при всех проверенных изменениях весов, поскольку в этой серии у него минимальная k и максимальная CTE. Когда вес k увеличивается на 20% или вес CTE уменьшается на 20%, GDHEYZO обходит GDHETZO. Критерии, границы, выбытие кандидатов и результаты каждого опыта можно проверить в [экспорте](../results/tbc/screening.xlsx). Балл 1.000 означает достижение лучших наблюдаемых значений в выбранном пуле. Практическую пригодность покрытия оценивают по отдельным испытаниям.

## Защита

| Вопрос | Короткий ответ |
| --- | --- |
| Зачем приводить единицы до фильтрации? | Порог задан в одной единице. Например, 1580 mW/(m·K) и 1.58 W/(m·K) описывают одно значение |
| Почему нельзя добавить измерение при 1400 °C в выборку k при 25 °C? | Температура изменяет перенос тепла. Результаты при 1400 °C принадлежат другой серии |
| Почему CTE при 1000 °C можно использовать рядом с k при 25 °C? | Это два разных критерия. Внутри каждого столбца условие одинаково для всех образцов. Вывод относится к выбранным точкам измерения |
| Как выбирались веса? | 0.65/0.35 — учебный приоритет тепловой изоляции. Анализ с ±20% показывает, насколько от него зависит порядок |
| Что меняется при добавлении нового кандидата? | Если меняются границы min–max, могут измениться оценки прежних кандидатов. Сравнивайте рейтинги с учётом состава пула и его диапазонов |
| Как проверяли ошибки? | Сверили шесть входных чисел, повторили расчёты вручную и автоматически проверили импорт, пограничные случаи, условия, экспорт и графики |

Для демонстрации запустите validate, покажите источник одного значения через Evidence, запустите screen и измените max для k с 1.8 до 1.65 в копии конфигурации. Останется SGDETZO с баллом 0.5 при постоянных критериях. Покажите, почему один кандидат означает нулевой диапазон. Для интерпретации приведите базовый рейтинг из трёх образцов.

## Распределение работы

| Участник | Ответственность | Часть защиты |
| --- | --- | --- |
| 1 | Поиск первичных источников, извлечение данных, DOI, условия и выбор сопоставимых серий | Обосновать TBC и сверить одно значение с публикацией |
| 2 | Схема HEC-DB, CSV/XLSX, правила импорта, единицы, пропуски и дубликаты | Показать объединение с набором другой группы и отчёт валидации |
| 3 | Min–max, взвешенная сумма, численная устойчивость, чувствительность и Pytest | Рассчитать один балл вручную и объяснить перемену позиций |
| 4 | CLI, графики, экспорт, инструкция запуска и подготовка слайдов | Воспроизвести запуск и сформулировать вывод вместе с его границами |

Перед сдачей участники 1 и 2 взаимно сверяют значения и режимы измерения. Участники 3 и 4 независимо сверяют ручную оценку с экспортом и запускают тесты в чистом окружении.
